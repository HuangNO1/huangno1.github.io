身為學術研究者，你是否也曾為實驗室網站的建置與維護而煩惱？

許多實驗室仍然依賴靜態的 GitHub Pages 或陽春的網頁模板，不僅更新繁瑣，更缺乏適當的內容管理功能。每當需要新增成員資訊、發布最新研究成果，或是更新實驗室動態時，都需要直接修改程式碼，這對非技術背景的研究者來說既不友善也不實用。

更令人困擾的是，大多數現有的解決方案缺乏國際化支援，無法同時服務中文和英文的使用者群體，這在國際化的學術環境中尤其不便。

為了解決這些長久以來的痛點，我開發了 Stellar Lab Web —— 一個專為實驗室設計的現代化網站框架。

## ✨ Stellar Lab Web 是什麼？

Stellar Lab Web 是一個現代化、通用的實驗室網站框架，內建完整的內容管理系統。它基於 Vue 3 和 Flask 構建，提供完整的實驗室網站解決方案，包含對外展示頁面和全面的管理後台。

這個框架的設計理念是「通用性」—— 任何實驗室都能輕鬆採用和客製化，無論是學校 Logo、實驗室資訊還是品牌標識，都能快速適應不同機構的需求。

## 🌍 國際化與主題支援

### 完整的中英文支援
提供完整的中英文介面切換功能，不僅僅是語言翻譯，更包含本地化的內容管理，讓國際化的學術環境中的使用者都能獲得原生的使用體驗。

### 淺色/深色主題
全站支援淺色和深色主題切換，無論是公開頁面還是管理後台，都能根據使用者偏好提供最舒適的瀏覽體驗。

不同於通用的 CMS 系統，Stellar Lab Web 專門針對學術實驗室的需求設計，每個功能都經過精心考量，確保符合學術環境的使用習慣。

基於 MIT 授權，完全開源且免費使用，實驗室無需擔心授權費用，也能根據自身需求進行客製化開發。

採用 Vue 3 + Flask 的現代化技術棧，不僅效能優異，更便於後續的維護和擴展。

提供完整的預設設定和範例資料，實驗室只需要替換自己的 Logo 和資訊，就能快速上線使用。
